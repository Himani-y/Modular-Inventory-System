# Modular Inventory System

A modular inventory system built in C# to practice clean, maintainable game-programming architecture.

## Current Features

- Add items to inventory
- Stack items by name
- Remove item quantities
- Find items
- Check item availability
- Get item quantity
- Input validation
- Basic error handling

## Tech Stack

- C#
- .NET
- Object-Oriented Programming
- Git & GitHub

## Project Goals

This project is being developed incrementally to demonstrate:

- OOP principles
- Interfaces
- SOLID principles
- Design Patterns
- Event-driven communication
- Clean Architecture
- Data-driven design
